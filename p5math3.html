📐 公式小抄（考試前看這張）

圖形S（面積）C（周長）
正方形（邊長 a）S＝a²C＝4a
長方形（長 a、闊 b）S＝abC＝2( a + b )
平行四邊形（底 a、高 h、斜邊 b）S＝ahC＝2( a + b )
三角形（底 a、高 h、另兩邊 b c）S＝ah ÷ 2C＝a + b + c
梯形（上底 a、下底 b、高 h、兩腰 c d）S＝( a + b )h ÷ 2C＝a + b + c + d
單位換算：1 m ＝ 10 dm ＝ 100 cm（每級 ×10）；1 m² ＝ 100 dm² ＝ 10 000 cm²（每級 ×100）。
大單位 → 小單位用乘法，小單位 → 大單位用除法；平方單位的小數點要移兩倍位數。代入公式前先統一單位。
四個最容易錯的地方：① 斜邊不是高，算 S 要用垂直的 h；② 三角形、梯形別忘 ÷ 2，反過來求高要先 × 2（平行四邊形不用）；③ S 用平方單位、C 用長度單位，別寫反；④ C 沒有萬用公式，把外圈每一條邊統統加起來。
記憶口訣：S 看裡面，C 繞一圈；平四底乘高，三角別忘半；梯形上下加，乘高再除二；高要畫垂直，單位別寫反。
